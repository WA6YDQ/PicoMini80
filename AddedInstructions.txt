emulator_2.c uses the following unused 8080 opcodes for additional instructions:

0x08	Floating Point co-processor instructions (2 byte opcode)
0x10	break - calls abort routine (same as pressing ABORTSW) (1 byte opcode)
0x18	lxi R0..R7 - Load registers R0 thru R7 with word (4 byte opcode)
0x20	Index copy with R0-R7 (2 byte opcode)

0x28	Increment/Decrement R0 thru R7 (2 byte opcode)
0x30	Branch (on condition), offset (3 byte opcode)
0x38	DAD Rn - 16 bit add from HL and R0 thru R7, result in HL. Flags Z, CY, S  (2 byte opcode)
0xCB	(unassigned)

0xD9	DSUB rp - 16 bit subtract: HL - rp, save result in HL. Flags Z, CY, S (2 byte opcode)
0xDD	(unassigned)
0xED	(unassigned)
0xFD	(unassigned)

---------------------- FLOATING POINT ---------------------
0x08	Primary Opcode Invoke Floating Point Instructions (2 byte opcode)

HL points to Result or String
BC points to Operand1
DE points to Operand2

Second Opcode
0x00	(unassigned)
0x01	ADD Result = Operand1 + Operand2 BC=Operand1, DE=Operand2, HL=Result
0x02	SUB Result = Operand1 - Operand2 BC=Operand1, DE=Operand2, HL=Result
0x03	MUL Result = Operand1 * Operand2 BC=Operand1, DE=Operand2, HL=Result
0x04	DIV	Result = Operand1 / Operand2 BC=Operand1, DE=Operand2, HL=Result
0x05	SQR Result = sqrt(Operand1)  BC=Operand1, HL=Result


0xfe	Float to String: BC points to floating point number (32 bits), HL points to null terminated string
0xff	String to Float: BC points to Null terminated ascii string, HL points to floating point result 

----------------- BREAK ---------------------------------
Primary Opcode (1 byte opcode)
0x10	BREAK (requires RESETSW or ABORTSW push, or console interaction to resume)
		The BREAK instruction stops operation, preserving all registers, flags and memory values.
		BREAK activates the abort function (same as pressing the ABORTSW) showing all the registers.
		Can be useful for debugging. Outputs to console ONLY.

------------------ BRANCH ---------------------
Primary Opcode Branch word (3 byte opcode: 0x30 [condition] [branch address])
Positive Offset (00H to 7FH) 0 to +127 past current instruction (offset=1, skip byte after BRA opcode)
Negative offset (80H to FFH) -128 to -3 bytes (FD jumps back to BRA, FC to the byte before BRA - BRA is 3 bytes)
0x30	BRA 
Second opcode (condition)
0x00	Always (unconditional branch)	
0x01	Z=1    	BRA Z offset
0x02	Z=0		BRA NZ offset
0x03	CY=1	BRA C offset
0x04	CY=0	BRA NC offset
0x05	S=1		BRA minus offset
0x06	S=0		BRA positive offset
0x07	P=1		BRA parity even offset
0x08	P=0		BRA parity odd offset
0x09	CY=1 Z=0 		A<B		(LT - less than)
0x0A	CY=0 Z=0 		A>B		(GT - greater than)
0x0B	CY=1 or Z=1  	A<=B	(LE - less than or equal)
0x0C	C=0			A>=B	(GE - greater than or equal)
0x0D	C=0 Z=1			A=B		(EQ - equal)

Based on 8080 Flags: 
• To jump if (A < B): Use JC (Jump on Carry).
• To jump if (A >= B): Use JNC (Jump on No Carry).
• To jump if (A = B): Use JZ (Jump on Zero).
• To jump if (A != B): Use JNZ (Jump on No Zero).



------------- DAD Rn ----------------
Primary Opcode 0x38  (2 byte opcode) ADD HL to Rn, save result in HL. CY set if result > 65535
Set Z on zero, S on minus
Second Opcode
0x00	R0		Add HL to R0 (allow saving value of R0 to HL)
0x01	R1		""  ""    R1 (by 1st clearing HL then adding)
0x02	R2		""  ""    R2 (so that LHLD and SHLD work on )
0x03	R3		""  ""    R3 (R0 thru R7)
0x04	R4		""  ""    R4
0x05	R5		""  ""    R5
0x06	R6		""  ""    R6
0x07	R7		""  ""    R7


----------- DSUB rp -------------
16 bit subtraction with register pair HL. Set CY on underflow, Z on zero, S on minus
Primary Opcode 0xD9
This is a 2 byte opcode.
Second Opcode
0x00	R0		Subtract R0 from HL, result in HL
0x01	R1		""       R1
0x02	R2		""       R2
0x03	R3		""       R3
0x04	R4		""       R4
0x05	R5		""		 R5
0x06	R6		""		 R6
0x07	R7		""		 R7

0x08	SP		""       SP
0x09	BC		""		 BC
0x0A	DE		""		 DE
