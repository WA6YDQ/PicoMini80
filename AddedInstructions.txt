emulator_2.c uses unused 8080 opcodes for additional instructions.

0x08	Floating Point co-processor instructions (2 byte opcode)
0x10	break - calls abort routine (same as pressing ABORTSW) (1 byte opcode)
0x18	Load registers R0 thru R7 with word (4 byte opcode)
0x20	General Operations with Index Regs R0 thru R7 (2 byte opcode)
0x28	Branch (on condition), word (4 byte opcode)
0x30
0x38


---------------------- FLOATING POINT ---------------------
0x08	Primary Opcode Invoke Floating Point Instructions
HL points to operandResult
BC points to Operand1
DE points to Operand2
Second Opcode
0x00	ADD operandResult = Operand1 + Operand2
0x01	SUB operandResult = Operand1 - Operand2
0x02	MUL operandResult = Operand1 * Operand2
0x03	DIV	operandResult = Operand1 / Operand2
0x04	POW operandResult = Operand1 ^ Operand2
0x05	SQR operandResult = sqrt(Operand1)
0x06	I2F operandResult = (double)Operand1 (converts 32 bit integer to a double float)
0x07

0x08	SIN operandResult = sin(Operand1) radians
0x09	COS operandResult = cos(Operand1) radians
0x0a	TAN operandResult = tan(Operand1) radians
0x0b	ASIN operandResult = arcsin(Operand1) radians
0x0c	ACOS operandResult = arccos(Operand1) radians
0x0d	ATAN operandResult = arctan(Operand1) radians
0x0e
0x0f

0x10	LOG2 operandResult = log_2(Operand1) 
0x11	LOG10 operandResult = log_10(Operand1)
0x12	LOGE operandResult = log_e(Operand1)
0x13	10X operandResult = 10^(Operand1) (anti log base 10)
0x14
0x15
0x16
0x17



----------------- BREAK ---------------------------------
Primary Opcode (1 byte opcode)
0x10	BREAK (requires RESETSW or ABORTSW push, or console interaction to resume)
